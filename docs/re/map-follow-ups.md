垂直硬边截面。用户已授权在修复英文地块标签后提交；道路、树木、资源图层不在本阶段继续实现。

## 道路与桥梁

- [ ] 解码区域 EcoPathSet 的真实中心线、PathEntry 类型和模板绑定。
- [ ] 按 static/realtime extrusion 配置生成道路挤出网格，加载对应 diffuse、normal、spec 材质。
- [ ] 根据 PathEntry 桥梁类型恢复桥面、桥头连接、附件实例及 stackToGround 支撑结构。
- [ ] 替换当前地下水零值 mask 推导的近似路带；验证真实道路不会遗漏，天然干旱地带不会误判。
- [ ] 覆盖普通道路、弯道、交叉口、跨水桥和高架桥的视觉检查。

证据与入口见 [道路桥梁调研](map-bounds-roads-and-bridges.md)。道路是样条挤出与附件实例组合，不能只给地形改色；桥梁不能仅凭水面判定。

## 树木与森林

- [ ] 恢复树种/模型或 impostor 资源选择、森林生态密度与摆放规则。
- [ ] 实现实例化、远近 LOD、裁剪与贴地，控制大地图的显存和绘制开销。
- [ ] 接入 forestColorMap 的远景树冠、阴影与近景树模型过渡，替换当前程序化树冠色斑。
- [ ] 核对道路/水体/陡坡排除规则，避免树木穿桥、浮空和长进河道。

生态 ED 的 G 通道是森林密度；`terrainPS` 单独采样 forestColorMap，不能把森林密度直接等同草地覆盖。

- [ ] 按游戏资源视图还原色带/等值线，并提供图例、透明度与选中状态。
- [ ] 验证资源覆盖不改动基础材质，并在切图、缩放和关闭图层时正确释放纹理。
