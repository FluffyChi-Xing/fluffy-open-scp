# 菜单移动与子分类分组

## 实现范围

工作台右侧增加独立的“分组管理”：创建普通顶层菜单下的一级子分类，可选中多项后创建分组并移入，也可批量移到已有目标。单项编辑 Sheet 增加“移动到”，应用当前草稿后移动。创建的分组可浏览、编辑其成员，在左侧父菜单预览中显示标签。

移动保持原菜单项 instance、原 property group 和已有编辑。导出从原生资源读取完整 uiCategories，依次应用移动操作，只替换源菜单对应的容器，保留未展示在工作台中的其他归属。复制项首次移动时固定其原导出 instance。源归属无法匹配、完整资源读取失败或只有浏览器环境时停止导出，不回退为不完整的合成建筑菜单。

区域占位菜单和住宅/商业/工业分区固定面板不提供分组。原生多级嵌套分组不在本次范围。文化等原有聚合菜单可创建新的目标分组；当前移动目标选择器包含普通顶层菜单和本次新建子分类，不把聚合父容器冒充可直接承载条目的叶子容器。

## 游戏格式证据

零售 `SimCity_Game.package` 的属性 dump：

- 道路：`00B1B104:09A4BA03:AC12C904`，原来无子分类组字段。
- 文化：`00B1B104:0C298BDD:94E412ED`，`0x0C2585B1` 为 **UInt32** `0F978DAC`；面板布局 `0x0C22F4DE` 指向 `67771F5C:0B074E5A:E99FFF56`。
- 地标子分类：`00B1B104:0F978DAC:3F43E038`，名称为 `0x0C2BF463` **Text[]**，顺序为 `0xCDCEF1AF` **Int32**。

零售提取 JS `tmp/js/template_registry.js` 的 `LoadRootToolPanel` / `LoadSubCategoriesToolPanel` / `LoadTools`：父菜单的 UInt32 字段决定枚举哪个资源组；子分类名称生成标签；子分类 instance 决定工具列表；子分类 layer key 可为 null。分区菜单特判调用 `LoadPaletteZones`，不会走此路径。

开发样本 `tmp/dev-sample-analysis/SimCity.unwrapped.exe.c` 945035 行附近同样显示按 UInt32 子分类组枚举 property instance、建立子分类到父菜单映射。此证据是结构解释，不是本次零售进程执行轨迹。

## 写回

`game_menu_groups_compile` 读取完整父菜单。已有子分类组时只向该组新增分类资源；普通菜单首次分组时覆盖父菜单的子分类组与面板布局，保留其余字段。默认“未分组”子分类使用原父菜单的容器 instance，放入新组，保持现有工具归属可访问；新子分类使用确定性分配的独立 instance。名称写入自有 locale 表，Text 数组使用原生 520 字节步长。

后端检查资源身份/组冲突，返回完整 TGI 和编码字节，前端统一装入 DBPF。重导出自有分组时仍包含父菜单与默认标签，避免覆盖包替换后丢失入口。

- 前端 store、组件及渲染相关测试共 28 项通过；包含多归属保留、跨视角导出、连续移动、复制项身份保留、失败阻断、空分组导出、分组操作及中英文切换。
- Rust 3 项测试通过，其中一项只读本机零售原包，分别编译道路和文化的子分类资源，验证字节往返、父菜单无关属性保持、面板布局引用存在。没有修改原包。
- vue-tsc 通过。
- 在本地工作台实际操作消防菜单：消防局移入新建“应急服务”后，新组 1 项、父菜单保留 2 项，预览出现“未分组 / 应急服务”标签。
