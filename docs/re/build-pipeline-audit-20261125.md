# 构建流水线阻断自查

日期：2026-11-25。范围：原生资产构建链、菜单注册、缓存/发布、三个实际生产项目。未改 SQLite 启动边界，未启动游戏或更换游戏包。

## 已修复的真实缺陷

1. **清理时机错误。** 原流程在缓存校验/新包验收前删除 `.build` 既有产物，导致缓存失效，而且构建失败也会丢失上次成功结果。现在只在新包完整通过并发布后、或校验命中缓存后清理旧 hash，保留当前成功 hash；失败和损坏产物拒绝覆盖路径继续保留原文件。增加了失败后旧成品仍可读取的回归断言。
2. **可选说明造成菜单资源缺行。** 新身份固定引用本地化第 2 行，未填写说明时原生成器不写该行。现在缺失或空白说明回落到作者标题，保持引用可解析；非空说明既有输出不变。增加标题独立配置测试与完整住宅菜单构建覆盖。
3. **身份增量审计对象错误。** DLC 几何 LotConfig 可位于 `58F0C000`，但身份克隆输出的是 Asset `40E1C000`；审计原来沿用几何组。现按身份资源的实际组比较，避免错误地跳过身份对比。对作者明确配置的尺寸认可原生尺寸列；容器生成的 UI/柱图列必须先通过精确 presentation 和分组柱图契约，才允许与 donor 不同。没有取消资源、渲染或写盘回读闸门。

另更新旧测试夹具：Building40 v9 原生旋转为 0 度，公园/地价需独立组件，不再让旧夹具要求已被禁止的共享池。住宅全链夹具补齐真实作者路径与完整原版菜单，验证新菜单身份，没有覆盖参照建筑资源。
