# 破洞体积材质回归

基于 `dev/rendering-optimisation` 的 `92670e7`。

引擎材质分支打开破洞时，视口会读取 `uBoxHalfXY.value`，但工厂此前未创建这个 uniform；补齐后还会遇到片元 GLSL 的 `texXform` 未定义、uniform 初始化局部 const，以及 float/int 算术类型错误。破洞同时复用了招牌顶点着色器，把所有面的深度固定在零，无法执行原内景片段的体积采样。

修复包含独立的盒体顶点着色器和尺寸接线，保留每个点的三维局部坐标；前景和内景使用相同方向的贴图变换。在调整房间日光贡献之前调用现有 `SimCityLighting`，避免从未初始化的零光照中减去太阳。生成器与提交的 GLSL 同步修改。招牌、涂鸦和全息图仍走各自现有路径。

## 真实 GPU 检查

运行 `pnpm dev` 后访问 `/tests/decal-hole.html`。全部纹理由代码生成，无需加载游戏包或用户存档。页面运行四个断言，结果保存在可见 JSON 和 `#result[data-status]`：

- 工厂提供的盒体尺寸能够被视口访问。
- 生产顶点/片元着色器编译、链接并输出非零像素。
- 环境光变化能改变内景采样的实际 GPU 输出。
- 后壁归一化深度为 -1，排除旧招牌顶点路径恒为 0 的回归。

本机 WebGL 实测全部通过：无光/有光中心像素分别为 `[64,96,128,255]` / `[80,120,160,255]`；深度诊断像素为 `[130,130,0,255]`。这些检查证明故障路径已恢复执行，不代表所有游戏破洞资产与原引擎像素一致。现有近似光照、图集拆分和遮挡策略仍需原游戏资产与同镜头画面验收。
