## 后续目标与验收

1. **时间与身份基础**：统一菜单、UnitEntry、运行实例、父子模块、规则、资源名和来源；加入游戏Hour/日期、营业标志、稳定实例身份。验收：同一实例可在多窗口关联，明确覆盖多少模拟时间、丢弃量与未知字段。
2. **水泵完整周期**：解码基础产水、地下水修正、发送、回流、统计刷新之间关系；对照属性Rate/Minimum/PerStep。验收：逐周期解释一次库存变化，跨确认的昼夜边界比较，识别缺电/地下水不足等条件，不主动修改存档制造条件。
3. **小学完整营业周期**：定位水电补给与消耗、污水垃圾生成、营业条件；覆盖6:00前、上课、15:00后。验收：区别补给、库存消耗、统计显示、模块汇总，解释停止的确切规则条件。
4. **教育与Agent链**：追踪入学、学习/考试、知识回传住宅/全局教育统计，再追校车、spawner与path。验收：一条可核实的因果路径，而非从可见人数猜计数。
5. **机制编辑闭环**：先完成只读解释和校验，再选单一已解析字段做用户授权的受控修改/回滚验证。暂不实现任意ER2写回。

## OpenSCP 功能收益

| 功能 | 研究结果带来的提升 | 前置条件 |
|---|---|---|
| 菜单/资产联动检查器 | 菜单可跳转行为Unit、模型、模块、规则；显示跨菜单复用和来源 | 引用与继承合并 |
| 语义属性编辑器 | 展示席位/产水量/周期而非哈希；区分基础值、继承值、模块汇总 | 符号、单位、作用域验证 |
| 资源与规则检查器 | 区分物资、状态、人口计数、统计；显示条件、applyCount、实际delta | 完整规则结构解码 |
| 运行诊断时间线 | 显示按游戏时钟何时启动/停止、库存为何不变；避免零日志误判 | 时钟/身份/覆盖验证 |
| 模块资产编辑 | 验证教室增加容量、车库增加车辆以及默认模块依赖 | 父子Unit与容量聚合 |
| path/spawner编辑 | 按行人/车辆/角色及行为引用校验路径和点位 | Agent、Transport、路径关联 |
| UI绑定检查 | 显示当前量/累计量/估算速率/本体或connectedUnits差别 | 查询绑定与资源周期 |
| Mod导出校验 | 检查引用缺失、覆盖顺序、规则依赖和不完整资产克隆 | 包来源与依赖闭合 |

优先落地只读身份/依赖检查、资源符号与单位提示、采集质量和时间线；复杂行为编辑需等语义与写回验证完成。新增界面必须同时维护zh-CN/en-US i18n。本轮仅研究与取证，未实现以上产品功能。
