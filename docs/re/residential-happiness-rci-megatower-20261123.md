## 日常收入与支出、离开住宅的规则

- 自长住宅模板继承分档税率转幸福的入口。W1 D2 为 `927C3F78 → 64BA425E`，W1 D3 为 `927C3F79 → 64BA425F`。W1 D3 后续有 `034FB96A` 增加幸福、`A44CAD5D` 扣除幸福，两者分别依赖幸福／悲伤的税率标记。所查塔层有效 bundle 列表中没有这些分档入口，三个地面配方的代码均明确保留各自的 D2 税率入口。
- W1 自长与塔层共享住宅 bundle `D4C30C02`。购物返家链 `104D6998` 可经 `88D12BAC` 增加购物幸福，缺少购物收益的规则 `5FFBA63D → 7E3DC339` 可扣幸福并记录悲伤。同一个 bundle 的 `246F5982 → 96FAFAE6 → 38127842 → 74A1CA8E` 含幸福前置资源操作与车辆事务，另有无家可归分支 `30F06C0A`。进入该链受控制旗标和资源条件影响。
- W1 巨塔入住事件 `81AA8640` 有额外分支，`1788982F → 29D96619 → 31DBACDA` 可在特定旗标条件下扣减在家人口并写塔层计数 `8808339F`。此外，塔层的 `EBFC1753` 注册 `387158A8`，其链使用劳工和消费者容量，并在 `31441923` 从 `D9108DD9` 读取动态值参与 HappinessToken 比较。原始操作中的 `999999` 和 `-1000000` 有动态代入与特殊操作语义，不能直接读作每次扣掉固定数量。
- 旧配方内部把 `0D6343C2` 局部变量命名为 `move_out`。规则专用化表把该属性接到 `11315A5A/E7AD5A87`。沿 `11315A5A → 91686553 → A64ECA3C → D5A6CAEA → A3A00571` 可达 `74611524` 的纵火犯生成分支。现有证据支持它接入犯罪事件，不能用变量名推断它是迁出率。三个财富档的 D3 RCI 原值也与对应塔层一致。

以上差异足以区分两套住宅样本的配置。巨塔是否在正常服务下出现过度迁出，仍需逐日运行数据验证。记录 `HappinessToken`、`HappinessDisplay`、`TotalResidents`、`TotalResidentWorkersW*`、`TotalResidentShoppersW*`、空置状态及返家事件。同一财富档在同城比较，分别记录上下班或购物时的在途波动，以及实际迁出后占用下降和补位。合建时由可放置建筑宿主提供唯一开关，住宅组件验证通过后再与观光或娱乐同场验证。
