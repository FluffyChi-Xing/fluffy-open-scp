# 原版建筑可编辑属性普查

## 样本和证据

以 OpenSCP 菜单快照中有名称且已绑定原版 Unit/Lot 的顶层菜单条目为总体。按「城市」「城市发展」分层，各自按 Unit 去重，排除仅有模块菜单绑定的条目。两个总体分别是 101 和 36 个 Unit。按记录排序后用 Python `random.Random(20261116)` 依次各无放回抽取 5 个。两条同名大喷泉公园实际有不同的 Unit 和继承链，均保留。燃油和融合电厂另作专项，未占抽样名额。

按完整 TGI 读取 Unit，记录每列的来源和叶级有效值，初步跟随启用 bundle、规则槽、sink 规则及成功/失败链，核对已经识别的容量绑定和 AEB 专用化操作。未追完的全局调度和可选模块路径保留为待验证项。原版 Scripts 基础与 EP1 包 SHA-256 分别为 `77DDCED4A23A818673E44C19649732390D8771BC5A1434583032E5841BAEDD04` 和 `0A3F66804D9A99A626509B42C76D3C308A53F9FB2D84529F621A88BF85043FF9`。基础与 EP1 AEB 分别完整解码到 EOF，UnitRule 数量为 28,441 与 5,485。各项结论来自离线读取，没有启动游戏或部署。金额为原始 Property 数值，其余数值为引擎内部单位。

## 石油发电厂

- 本体 `00B1B104:40E0C000:6E296726` 的 `0DB75503=20000` 是原油容量。启用的 `00C3DC49`、`114B720A`、`16D55F40` 通过 `0A6FE749/4A` 将 OilCrude 容量绑定到该列。基础 bin 表另有 1000 或 0 的声明值，构建应优先保留原版容量绑定。规则 `163AAC79`、`133AA7A5`、`775D824B` 还使用同列计算比例阈值。
- 本体预装传统发电机 `3A2900B1`，可选燃气 `A2EE7C8C`、化石燃料 `3B1072ED`。三个模块的 `0BBBD59A` 分别为 12、4、8，`0AFB9881` 都是 5000。本体对应两列都是 0。耗油和发电数值应写入实际模块。
- `B4CE30A4`、`D74D29C7`、`353ACE73` 分别读这两个字段的 1、1/2、1/4 系数，对应用油和送电计数，并同步统计写入。传统发电机的专用化结果为每次规则应用耗油 12/6/3，写入 `PowerToTransmit` 为 5000/2500/1250。以上是内部规则量。实际供网总量还取决于调度、模块、供油与输送。
- 可先验证传统发电机耗油 12→8、产出 5000→6000，以及本体库存 20000→24000（分别测试，再测试组合）。这些是验证用档位。用油初版可限制为正的 4 的倍数，避免分档与备用分支的整数舍入。变体应为发生编辑的预装和可选子模块分配自己的身份，并同步本体预装和变体的模块菜单绑定。

## 融合发电厂

- 原版菜单 `00B1B104:61F0C900:CB93D144` 指向模拟 Unit `00B1B104:61EFC000:34E340A2`。图形 Lot 在 `61F0C000`。厂本体 `0AFB9881=0`，预装标准反应炉 `9EB0C55F` 为 6667，进阶反应炉 `38DF277A` 为 80000。EP1 规则 `3DE97820` 由此专用化发电应用次数。仍须连通启动、运行和送电。
- UI 的 ControlNet 查询使用 `academyskill`。以精确 FNV-1 校验得到 `5737C2E4`，可在本体与预装反应炉的规则中看到。本体可达的 `674C1853` 直接消耗该资源 2 个内部单位，没有绑定到数值属性；`1C73FF5F`、`2E3A9E18` 有接收或转移操作。链还含 ControlNet Off 事件 `6A9415B0` 和补充、清空分支，例如 `952EC967`、`E63D01EF`。这些分支存在于原版规则图。各运行阶段的实际频率和控制旗标尚未对拍。
- 共同属性 `0FD16C0F=60` 已确认流入 `C7AC7C5D/B3C085D2/760C305A` 的全局资源测试项 `71E5D7AD`。该资源的具体角色仍待核实，其他 `0FD16C0B/12/15` 也尚无完整绑定证据。可以在高级只读视图显示这些证据。
- 要提供「无需 ControlNet」，需为变体单独保留充电、启动、运行、停机和重新启动的状态机，定位并替换其 ControlNet 供给和消费分支，同时保留外部供电及异常处理。需要独立的 EP1 Unit、子模块与规则注册支持。首版可提供只读依赖和已有发电参数，待无 ControlNet、充电、断电恢复、多个反应炉及存档重载均通过后再开放开关。

## 编辑器建议

1. **可以优先开放的数值。** 建造费用、维护费用。劳工采用成组配方，保持岗位合计与最低用工一致，并校验实际劳工规则。已经找到明确规则消费者的地价系数可作为独立候选，区域选择保持原值。
2. **有规则证据、需联动的数值。** 水电消费、生产速率、资源仓储、污染。按叶级有效值与绑定构建稳定配方，保留容量与初值关系，检验消耗阈值、统计及输出线路。每个字段的安全范围需按所属规则逐个确定，不能用统一增幅代替。
3. **暂时只读。** 未确认用途的继承容量、地标实际游客上限、采掘和制造链未知操作、ControlNet 开关。对于决定运行分支的输入，用专用配方和独立变体身份，而不是任意字段编辑。验收时检查现场产生的资源、停供恢复、UI 统计及重载。
