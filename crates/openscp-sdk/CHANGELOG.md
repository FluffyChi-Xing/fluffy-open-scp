# Changelog

## 0.1.0 — 2026-11-28

- Unified format/package/properties/RW4 Cargo facade with optional features.
- Shared ResourceId identity and checked conversion from u64 manifest instances.
- Borrowed memory package inspection, explicit input/index admission limits,
  and per-resource decoded output limits.
- Codec-preserving errors with machine-readable categories and source chains.
- Independent consumer, synthetic fixtures and real Simoder source adapter checks.
- Separate SDK release version from the desktop workspace version.

Release gates and exclusions: [0.1.0 contract](https://github.com/FluffyChi-Xing/fluffy-open-scp/blob/sdk-v0.1.0/docs/native-sdk-0.1.0-release.md).
