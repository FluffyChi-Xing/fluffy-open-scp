# SC5 Asset Packager 0.8.0 源代码

本压缩包是当前 0.8.0 的源码快照。包含窗口界面、原生编译器、预览、菜单、道具、灯光、公园行为预设、配置、测试及必需的小型运行模板。

## 开发环境与运行

使用 Windows 64 位、完整 Python 3.12（安装时包含 Tcl/Tk）。本机验证环境为 Python 3.12.14；依赖版本记录于 requirements.txt。

在本目录执行：

```powershell
python -m pip install -r requirements.txt
python sc5_packager_gui.py
```

不包含 Python 解释器或已经安装的依赖。窗口启动还需要系统图形驱动支持现有 WGL/OpenGL 预览。

## 重新生成 EXE

```powershell
python build_source.py
```

或执行 `构建源码版.ps1 -Python "你的 python.exe 路径"`。成品位于 `release/0.8.0/SC5 Asset Packager.exe`，不会自动生成发行压缩包。

`build_source.py` 使用当前 Python 的实际安装目录，解决原始构建脚本中本机 Python 路径的问题。原来的 build_exe.ps1、gui_build.spec 保留在包内供追溯；跨电脑构建请优先使用 build_source.py。构建辅助脚本不改写原始 gui_build.spec。

## 源码结构

- sc5_packager_gui.py：窗口界面与操作流程。
- sc5_packager.py：项目管理、检查、计划与编译入口。
- backend_compile.py、engine/：LOTM9、RW4、材质、原生地块与 Package 编译。
- behavior_profiles.py、behavior_native_profile.json：首个原生公园功能配方及版本证据。
- preview_*.py：三维预览；asset_transforms.py：朝向变换。
- menu_*.py、prop_contract.py、light_contract.py：菜单、道具与灯光对接。
- prop_assets/、brand_assets/：道具预览与品牌图片。
- vendor_tk/：当前版本使用的 Python Tk 窗口封装源码；系统仍须提供 _tkinter 与 Tcl/Tk。
- test_*.py、qa_*.py：自动测试和专项验证脚本。

engine/ 中少量 RW4、PNG、BIN 是当前编译器需要的研究模板，不是完整游戏资源包；prop_assets/ 是道具预览素材。不能删掉它们后仍按完整功能构建。

## 输入与游戏资源

打包需要 Blender 插件导出的资产文件，以及本机合法安装的 SimCity 资源。游戏路径在窗口中选择；仅供读取。不包含游戏原始 Package、个人资产项目、城市存档、已打包测试包、旧 EXE、缓存和历史构建目录。

部分旧 QA 脚本引用本机 Blender、游戏或 Projects 中的测试资产。它们作为历史测试源码保留，跨电脑需调整路径并准备测试输入，不能将“缺少测试素材”误判成程序运行依赖缺失。prepare_engine.py 是历史基线提取脚本，不要用它覆盖已有 engine。

不依赖原工作区的研究文件夹才能运行主打包流程；当前 engine 已随源码包提供。原生公园配方需要匹配已研究资源的哈希，不会在版本不符时静默跳过检查。

## 功能边界

0.8.0 提供旧版兼容和基础公园预设；公园实际城市作用尚待游戏验证。教育、供水等完整功能尚未开放。旧 README 和阶段报告描述的是历史阶段，最新用户说明见 docs/0.8.0使用说明.md。

source-manifest.json 逐项记录打包文件的 SHA256，可用于核对源码快照。未在此源码包中新增或推定开源许可证；保留各源文件与第三方组件原有声明。
