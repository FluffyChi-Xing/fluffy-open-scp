# 0.4.0 朝向预览与日间内景修正

## 用户实测事实

用户确认 0.3.0 生成的新建筑能进入游戏，但朝向不符合预期，白天存在明显亮窗。本版继续三维预览阶段，并将输出目录提示作为同一任务补充。没有修改用户源资产、游戏文件或存档。

## 朝向问题出处

旧 `engine/prepare_asset.py` 对所有模型位置/法线/切线固定乘 `[-1,-1,1]`，`backend_compile.py` 同时固定将遮罩双向反转。这是希望大厦研究时使用的“源 -Y 转游戏 +Y”约定。新建筑的实际入口不一定在源 -Y，因此不能把固定 180 度当作每个建筑的正确朝向。

修复：新增 `asset_transforms.py`，共享 0/90/180/270 的精确旋转矩阵；预览与编译调用同一函数。地块 Raster 采用与世界坐标相符的四分之一圈变换，90/270 交换宽深/周期，偏移向量同向旋转。碰撞从旋转后的几何重新编译。成品包增加实际朝向边界核对。

界面新增蓝色临街 +Y 箭头与道路参考线；相机环绕不改变资产朝向，“导出旋转”及左右转按钮才修改并保存项目设置。没有实现或声称自动识别建筑主入口。

## 日间亮窗出处

对用户 `Box001.002_原生.lotm` 直接只读检查：源插件版本为 1.23.7，profile 为 `native-room-states-transparent-top-v3`，109 材质组、57,430 三角形。带内景采样的 71 组中，有 51 组采样日间状态 Alpha 非零。部分源配方使用 scale=0.125、offset=0.25，不能只按 Office 的 1/16 配方处理。

旧 `prepare_asset.py` 仅对 `window-relative-relief-hdr-room-v2` 的 Office 配方进行专项迁移。其他源房间数据直接重采样，日间 Alpha 也原样带进成品。插件 `native_asset.py` 对通用房间执行整体发光增益，并未在所有非 Office 配方中统一清除日间格。profile 名称不构成所有窗型已无日间自发光的证据。

原生 shader 通过 `variation*4 + state` 选择房间格，内景颜色还受 Alpha 乘原生自发光增益影响。因此源日间格 Alpha 非零，是一个可直接定位的遗漏，与用户截图现象相符；不能只对几何或窗户颜色整体调暗。

修复：保留原来 16 格的重采样坐标，不重排 RGB，不修改房间投影参数，不再次套用 HDR 降低系数。默认 `night-only` 策略仅将每组四态的非夜景格 Alpha 置零，状态 1 的全部 RGBA 保留；已暗窗的夜间 Alpha 仍为零。成品内景纹理解码后逐项核对，不只检查打包前 PNG。保留 `preserve-source` 配置值供独立研究对照，但窗口默认使用修复策略。

本版保留原生内景控制器启用属性 `0F169C46`，没有用强制常亮或禁用内景掩盖状态问题。白天仍允许自然室内 RGB 和玻璃反射可见，所清除的是额外自发光。实际屏幕亮度还需游戏实测。

## 三维预览与预检

新增 `preview_3d.py` 与 `preview_panel.py`，使用 LOTM 内嵌几何和 glTF 预览颜色，离线投影绘制，支持环绕、缩放、适配视角、建筑/地块分别显示。预检显示尺寸、顶点、三角形、材质组和缺失地块等问题。

实际资产四个朝向预览均生成成功；90 度时模型尺寸 X/Y 与地块宽深按预期交换。该预览采用软件绘制和近似颜色，地面为权重颜色示意，不等同原生游戏 shader。长三角形的颜色和遮挡可能与游戏预览不同，不将预览当作昼夜视觉验收。

窗口检查发现并修正了 Notebook 与 pack 混用、分栏在布局未完成时设置而被夹到零、底部指标被 Canvas 挤占的问题。真实资产的窗口加载、朝向保存及成品目录可见性检查通过。

## 输出目录提示

此前日志主要列出 reports 下的构建报告，用户容易误认为没有输出或不知道包在哪里。本版持续显示 `<项目>/output`，提供打开目录按钮，并在完成弹窗和日志列出本次实际生成的 `.package` 完整路径。

`build-result.json` 增加 `outputDirectory` 和 `packages`。构建前后比较输出文件信息，若后端退出码为零但没有本次新写入的 Package，则判定未完成，不把旧包算作本次成功。新增回归检查验证该情况。

## 验证结果与边界

- 几何/法线旋转、非对称遮罩四分之一圈变换、宽深/周期/偏移同步及逆变换检查通过。
- 合成内景 16 状态全部 RGB 保留、夜间 RGBA 保留、非夜间 Alpha 清零、暗窗仍暗检查通过。
- 源资产预览读取 118,866 个顶点、57,430 个三角形及 109 组材质；四向输出无报错。
- 真实窗口测试载入模型、左右转保存、成品路径显示通过，文件列表宽度 453 像素，统计栏高度 38 像素，均未被挤掉。
- 初次修复包 93,673,848 字节，0 度，仍为 57,430 个三角形，71 组内景状态回读，51 组原有日间自发光归零，夜间保留；最终 EXE 回归另见发布验证记录。
- 7 项自动化检查通过，包含原有项目打开与新输出路径门禁。
- 整包 DBPF、两套读取器、引用、碰撞、原生属性和数值数据检查继续通过；游戏文件元数据与核心包哈希在构建前后未改变。

用户需用新生成的建筑复测白天/夜间正侧视、入口临街、地面和占地、选择及拆除。`runtimeVerified` 保持 false。本版没有修正拆除过渡变形，也不新增学校服务。
