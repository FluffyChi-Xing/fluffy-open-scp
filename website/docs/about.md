# 为城市的另一面，打开一扇窗。

OpenSCP 是面向 **SimCity (2013)** 的开源 `.package` 资源浏览器与模组工具链。它从经典工具 SimCityPak 的现代化重写出发，逐步连接资源解析、可视化编辑、模组构建与引擎研究。

你可以用它查看游戏资源结构、预览模型和材质、编辑属性与文本，并将资源导出到其他创作工具。

## 为什么做 OpenSCP

一个建筑的最终表现，往往分散在模型、贴图、属性表、贴花与运行时规则中。OpenSCP 希望把这些线索放在同一张工作台上，让资源之间的关系可以被阅读、验证和复用。

项目使用 **Rust + Tauri 2 + Vue 3**。底层解析器以独立 Rust crate 组织，不依赖桌面界面；工作台在本机读取你提供的游戏文件。

## 三个相互连接的方向

| 方向 | 当前关注 |
| --- | --- |
| 可靠的格式底座 | DBPF 容器、RefPack 解压、RW4 模型与贴图、Property 属性表 |
| 可用的资源工作台 | 资源树、TGI 筛选、模型与地图预览、文本与 Raster 编辑 |
| 可复用的模组工作流 | Overlay 写回、复写检测，以及规划中的声明式构建 |

已实现的能力与未来目标分别记录在[开发进度](./development)中。截图来自开发中的应用，具体表现请以你安装的版本为准。

## 研究与工具一起生长

我们将游戏格式与渲染机制的分析整理为[研究档案](./research/)。文章应说明结论来自哪里、如何验证、有哪些适用范围，供模组作者与研究者继续核对。

官网首批研究文章是现有项目文档的双语摘要，不等同于对全部引擎行为的完整说明。
