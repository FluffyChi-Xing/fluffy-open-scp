# GlassBox 引擎简介

GlassBox 是 SimCity (2013) 的模拟引擎。它是一个**数据驱动**的架构：
引擎本体只是通用的解释器与调度器，行为数据（规则、资源表、代理参数）
全部存放在 `.package` 数据侧。

## 分层结构

```
GB 命名空间（85 类）  引擎运行时：游戏管理、状态机、delta 同步、物理世界
SC 命名空间（325 类） 游戏模拟层：代理、交通管流、渲染常量
Swarm (EA)            粒子与群集系统（人流/车流底层）
Bullet                物理中间件（仅表演层：碎片/贴地/分离）
Wwise                 音频中间件
```

## 核心模拟机制

- **管流交通（Transport Pipe）**：道路是"管道"，车辆/行人是在管道槽位中
  流动的代理；拥塞按占用数分级调度（分布式 LOD）。
- **薄代理 / 重池**：agent 本体只是数据行（哨兵 id + 少量参数），位置与
  状态全部外置在池和格网中。
- **场 + 流经济**：资源以地图网格标量场表达，由 Swarm 流随时间搬运。
- **规则数据驱动**：`cBeatRuleHandler` 以节拍驱动规则表，事件队列即背压阀。

## 与模组的关系

- 游戏行为改调平 = 改 package 里的属性表，不需要动引擎；
- 本工具（OpenSCP）的 property 编辑 / overlay 写回正是利用这一点：
  修改数据侧即可改变模拟行为。
- 引擎是 32 位单体 exe，规则哈希存于数据表而非指令立即数——离线分析
  需要从 RTTI 与数据表两头夹逼。
